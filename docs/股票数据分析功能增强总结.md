# 股票数据分析功能增强总结

## 概述

本次增强为 AI 荐股功能添加了丰富的数据分析维度，充分利用了后端已有的数据工具，让 AI 能够进行更全面、更深入的股票分析。

## 后端增强

### 1. 增强的 AI 提示词 (`backend/data/stock_pick_service.go`)

**新增内容：**
- 详细列出了所有可用的数据分析工具及其用途
- 明确了工具使用优先级和策略
- 添加了"工具使用策略"章节
- 增强了"深度分析阶段"的指导
- 更新了"输出要求"，要求更详细的数据分析

**可用工具列表（按优先级）：**

| 工具名称 | 用途 | 数据来源 |
|---------|------|---------|
| `ChoiceStockByIndicators` | 自然语言筛选股票，获取技术指标和财务数据 | 问财 |
| `QueryStockKLine` | 获取 K 线数据进行技术分析 | 新浪/腾讯财经 |
| `GetFinancialReport` | 获取财务报表进行基本面分析 | 雪球 |
| `QueryShareholderCount` | 分析股东人数和筹码集中度 | Tushare |
| `QueryStockNewsTool` | 获取相关新闻和资讯 | 财联社 |
| `GetIndustryResearchReport` | 获取行业研究报告 | 市场新闻 API |
| `QueryEconomicData` | 获取宏观经济数据 | 市场新闻 API |

## 分析维度说明

### 技术面分析
- **趋势判断**：上升/下降/震荡趋势
- **RSI 指标**：相对强弱指标，判断超买超卖
- **MACD 指标**：指数平滑异同移动平均线，判断买卖信号
- **KDJ 指标**：随机指标，判断超买超卖
- **K 线形态**：支撑位、压力位、量价配合

### 基本面分析
- **PE (市盈率)**：估值水平
- **PB (市净率)**：资产估值
- **ROE (净资产收益率)**：盈利能力
- **营收增长**：成长性分析
- **利润增长**：盈利质量

### 筹码分析
- **股东人数变化**：判断筹码集中/分散
- **人均持股**：分析主力控盘程度
- **变化趋势**：多个季度的趋势分析
- **信号判断**：主力吸筹/出货信号

### 舆情动态
- **相关新闻**：最新资讯汇总
- **利好利空**：消息面分析
- **行业动态**：相关行业资讯
- **市场情绪**：投资者情绪判断

## 使用流程

1. **用户输入选股需求** → 例如："推荐几只科技股"
2. **AI 理解需求** → 分析用户意图
3. **筛选候选股票** → 使用 `ChoiceStockByIndicators` 初步筛选
4. **深度数据分析**（对每只候选股票）：
   - 调用 `QueryStockKLine` 获取 K 线
   - 调用 `GetFinancialReport` 获取财报
   - 调用 `QueryShareholderCount` 分析筹码
   - 调用 `QueryStockNewsTool` 获取新闻
   - （可选）调用行业报告和宏观数据
5. **综合分析评分** → 整合所有维度数据
6. **生成推荐报告** → 输出完整分析

## 注意事项

1. **数据可用性**：所有分析都基于真实可获取的数据，如某工具调用失败会优雅降级
2. **错误处理**：工具调用失败时会提示"该维度数据暂不可用"
3. **性能考虑**：建议 AI 先筛选出少量候选股票（5-10只）再进行深度分析
4. **监管合规**：所有分析仅供参考，不构成投资建议
