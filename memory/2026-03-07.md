### 分析了 coding-agent 技能

**功能概述：**
- 这是一个让 OpenClaw 调用各种代码代理的技能
- 支持运行：Codex CLI、Claude Code、OpenCode、Pi Coding Agent
- 通过后台进程方式运行，支持 PTY 终端交互

**核心特性：**
- 必须使用 `pty:true` 保证终端正常工作
- 需要 Git 仓库环境（Codex 只在可信 Git 目录运行）
- 支持快速一次性任务和后台长时间任务
- 可并行处理多个任务（比如同时修复多个 Issue）

**使用场景：**
- 快速代码生成（比如构建深色模式开关）
- 复杂项目构建（比如从头构建游戏）
- PR 代码审查
- 并行问题修复

**使用示例：**
```bash
# 快速任务
bash pty:true workdir:~/project command:"codex exec --full-auto 'Add error handling'"

# 后台长时间任务
bash pty:true workdir:~/project background:true command:"codex --yolo 'Build a REST API'"
```

这个技能让 OpenClaw 变成代码代理调度器，而不是自己直接写代码。

### 配置了 coding-agent 为默认编码工具

**配置内容：**
- 创建了 TOOLS.md - 详细的工具使用规则
- 更新了 AGENTS.md - 添加编码任务配置规则
- 创建了 CODING_AGENT_CONFIG.md - 核心配置文件

**核心规则：**
1. **所有写代码任务必须使用 coding-agent 技能**
2. **默认使用 Claude Code**（除非用户明确指定其他工具）
3. **OpenClaw 只负责调度** - 不直接写代码
4. **Claude Code 真正执行** - 代码生成、修改、审查等

**触发词（必须使用 coding-agent）：**
- "帮我写..."、"帮我修改..."、"帮我重构..."
- "帮我审查..."、"帮我添加..."、"帮我创建..."
- "帮我实现..."、"帮我修复..."、"帮我优化..."
- 任何涉及代码编写、修改的请求

**执行流程：**
1. 识别任务类型 → 是否为编码任务
2. 是 → 加载 coding-agent 技能
3. 选择工具 → 默认 Claude Code
4. 执行命令 → 必须带 pty:true
5. 监控进度 → 后台任务用 process 工具
6. 完成汇报 → 告诉用户结果

**创建的文件：**
- TOOLS.md - 本地工具配置和使用规则
- CODING_AGENT_CONFIG.md - 核心配置（不可更改）
